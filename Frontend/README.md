# 🚖 E-Riksha Booking App

A modern web application for booking electric rickshaws, designed for convenience, speed, and eco-friendliness. Built with the MERN stack, this project simulates a ride-booking platform tailored for urban mobility.

---

## ✨ Features

- 🔎 Search and book e-rikshaws in real-time
- 📍 Google Maps integration for route and location tracking
- 👤 User login & registration
- 🧑‍✈️ Driver dashboard and ride management
- 💳 Payment integration (coming soon)
- 📱 Fully responsive UI for mobile and desktop
- 🔐 Authentication with JWT
- 📦 RESTful APIs for robust backend communication

---

## 🛠️ Tech Stack

**Frontend**: React, TailwindCSS, Axios  
**Backend**: Node.js, Express  
**Database**: MongoDB (Mongoose)  
**Authentication**: JWT  
**Tools**: Git, Postman, Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js & npm
- MongoDB (local or Atlas)

### Installation

```bash
# Clone the repository
git clone https://github.com/Pawan23Rathee/E-Riksha-Booking-app.git
cd E-Riksha-Booking-app

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env
# Add your MongoDB URI and JWT secret in the .env file

# Run the app
npm run dev
